# 회귀 테스트

Node.js 18 이상에서 프로젝트 루트 기준으로 실행합니다. 별도 패키지 설치는 필요 없습니다.

```powershell
node --test tests/regression.test.cjs
```

`voice-rts.html`의 실제 스크립트를 읽어 실행합니다. DOM, 음성 인식기, 타이머는 모사하며 다음 동작을 검증합니다.

- 부대 이름·번호, 생산 수량, 구역 및 커서 위치 해석
- 초기화 이후 지연된 음성 이벤트 무시와 정상 인식 재시작
- 실제 키다운·키업 처리기를 통한 연속 스페이스 입력, 무음 입력, 키 반복, 확정 지연·타임아웃 및 생산 명령 중복 방지
- 조기 실행 보정 시 다른 명령 및 취소 이력 보존
- 실패한 명령의 기록, 빈 결과와 해석 실패 시 조기 실행 복원
- AI 응답 순서, 게임 초기화, 요청 당시 선택 대상 유지

음성 보정은 해당 발화가 변경한 유닛만 되돌립니다. 더 최근 명령을 받은 유닛은 수정하지 않습니다. 새로운 입력이 발생하면 이전 AI 응답은 폐기합니다.

스페이스바를 누를 때마다 새 인식기로 입력을 시작하며, 결과는 발화별로 보관합니다. 키를 떼면 녹음을 중단하고 마지막 결과만 기다립니다. 그 전에 다시 누르면 이전 발화는 현재까지 받은 결과로 마감하고, 이후 도착하는 이전 인식기의 이벤트는 무시합니다. 대기 중 인식기를 계속 켜 두던 예열 옵션은 제거했습니다. 새 입력에서는 마이크 준비 신호음 이후 말해야 합니다.

실제 마이크 권한, 음성 인식 서비스 연결, 인식 정확도와 화면 배치는 이 테스트가 검증하지 않습니다. 해당 항목은 `실행.bat`으로 실행한 브라우저에서 별도 확인해야 합니다.
